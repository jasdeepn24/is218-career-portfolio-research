## Skills to learn and evidence to create

These are gaps in the supplied evidence, not claims that the student has never encountered a topic.

1. **Application foundation:** Practice HTTP APIs, SQL/data modeling, authentication, input validation, and integration tests. Proposed check: a small service handles invalid input and has reproducible setup and tests.
2. **Delivery:** Learn CI/CD, code review, deployment, secrets handling, and monitoring. Proposed check: a clean checkout passes checks and a test deployment can be diagnosed and rolled back.
3. **Data and AI:** Extend Excel analysis into Python data work; study ML fundamentals, RAG, model evaluation, and privacy. Proposed check: a small public-data prototype has a baseline, held-out cases, documented failures, and human review. Do not use real HR records.
4. **Later production depth:** Learn containers, cloud services, model operations, security, and reliability through supervised work. These require experience beyond a class demonstration.

Start with the application and data foundations, then pursue internships appropriate to demonstrated skills. Evaluate interest through small projects before committing to the advanced AI route. No invented timeline promises senior-role readiness.
